If we imagine each combination as a node in a tree, the total number of nodes is 9^5 = 59 049

Can there be a strategy that can solve the game under 10 turns?
  Obviously yes as the total number of colours is less than 10
  


Total information = log2(59049) = 15,85 bits
Information gain per turn = log2(3^5) = 7,92 bits

Total information / Info. gain per turn = 15,85 / 7,92 = 2,00126… turns
